# 📚 Flashcard Quiz App - CodeAlpha Internship

## 📝 Description
A simple and clean Flashcard Quiz App built for studying. 
This project is a part of my **App Development Internship at CodeAlpha**.

Users can learn with flashcards - each card has a Question on the front and Answer on the back. Users can navigate, add, and delete cards easily.

## ✨ Features
- **Show Answer Button:** Question on front, Answer on back
- **Navigation:** Next / Previous buttons to move between cards
- **Add Flashcards:** Add your own custom Question & Answer
- **Delete Flashcards:** Remove any card you don't need
- **Clean & Simple UI:** Easy to use on mobile and desktop
- **Card Counter:** Shows Card 1 / 3 etc.

## 🛠️ Tech Used
- HTML - Structure
- CSS - Styling & Design
- JavaScript - Logic & Functionality

## 🚀 How to Run
1. Download / Clone this repo
2. Open `index.html` in any browser
3. Start learning with flashcards!
